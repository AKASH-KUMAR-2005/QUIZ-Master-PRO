# QuizMaster Pro Advanced

7-page responsive quiz application:
1. Home
2. Student Login
3. Student Dashboard
4. Quiz
5. Result
6. History
7. Admin Login + Admin Dashboard

## Student
Any non-empty name, ID and password works in this frontend demo.

## API
Open Trivia DB is used for live multiple-choice questions. The app falls back to a small local bank if the API is unavailable or returns fewer questions.

## Important
Authentication and data storage are browser-only because this version has no backend. Do not use the demo credentials for real security.
